# auth_service

Сервис аутентификации платформы «Маршруты победы».

## Запуск

```bash
uv sync
cp .env.example .env
mkdir -p keys
openssl genpkey -algorithm RSA -out keys/jwt_private.pem -pkeyopt rsa_keygen_bits:2048
openssl rsa -pubout -in keys/jwt_private.pem -out keys/jwt_public.pem
uv run uvicorn main:app --reload --port 8001
```

## Модель авторизации

- **Формат токена:** JWT, алгоритм **RS256**. `auth_service` — единственный
  держатель приватного ключа; `user_service` и прочие проверяют подпись
  публичным ключом локально (без сетевого вызова на каждый запрос).
- **Пара токенов:** короткий `access` (~15 мин) + длинный `refresh` (~30 дней).
  `refresh` хранится в Б\Д (таблица `refresh_tokens`), при обновлении — ротация
  со старого на новый (детект переиспользования → отзыв всей цепочки).
- **Пароли:** Argon2id (`argon2-cffi`).
- **Роли в токене:** `family` / `searcher` / `local_historian` / `mentor` /
  `moderator` — под разделы кейса («Поисковый штаб», «Живая память», права
  верификации).

## Способы входа (обсуждаем)

1. **Телефон + SMS-код (OTP)** — основной для мобильного приложения, низкий
   порог входа для семейной аудитории и пожилых поисковиков.
2. **Email + пароль** — запасной, для веб-версии и краеведов/музеев.
3. **OAuth: VK ID / Yandex ID / Госуслуги (ЕСИА)** — быстрый вход + для
   верифицированных ролей (поисковик, краевед) даёт подтверждённую личность.
4. **Гостевой режим** — семейный маршрут можно пройти без регистрации,
   прогресс живёт локально; регистрация предлагается при попытке сохранить
   «Живое фото» или записаться на выезд.

Эндпоинты (черновик): `POST /register`, `POST /login`, `POST /otp/request`,
`POST /otp/verify`, `POST /token/refresh`, `POST /logout`, `GET /.well-known/jwks.json`.

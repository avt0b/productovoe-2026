# user_service

Профили пользователей платформы «Маршруты победы».

## Запуск

```bash
uv sync
cp .env.example .env
# положите публичный ключ auth_service в ./keys/jwt_public.pem
uv run uvicorn main:app --reload --port 8002
```

## Ответственность

- Профиль: имя, город, роль, аватар, настройки уведомлений (в т.ч. подписка
  на «поисковую деятельность» и радиус пуш-оповещений «Последний бой»).
- Привязка к поисковому отряду (для роли `searcher`), статус верификации
  (для `local_historian` / `mentor`).
- Достижения и прогресс по маршрутам (геймификация).

Аутентификацию **не** делает — принимает `access`-JWT от `auth_service`
и проверяет подпись публичным ключом (RS256).

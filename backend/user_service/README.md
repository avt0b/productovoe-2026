# user_service

Профили пользователей платформы «Маршруты победы».

## Запуск

```bash
uv sync
cp .env.example .env      # JWT_SECRET должен совпадать с auth_service
uv run uvicorn main:app --reload --port 8002
```

Swagger — <http://127.0.0.1:8002/docs>.

## Архитектура

Тот же трёхслойный скелет, что и в `auth_service`:

```
api/      # HTTP-слой: роутеры, pydantic-схемы, deps
core/     # config, security (проверка JWT), db (позже), models/ (позже)
main.py   # сборка FastAPI
```

Пока сервис содержит только проверку токена (`core/security.py`,
`api/deps.py`) и пример защищённого эндпоинта `GET /whoami`. Слои `services/`
и `repositories/` появятся вместе с моделью профиля.

## Ответственность (план)

- Профиль: имя, город, роль, аватар, настройки уведомлений (подписка на
  «поисковую деятельность», радиус пуш-оповещений «Последний бой»).
- Привязка к поисковому отряду (роль `searcher`), статус верификации
  (`local_historian` / `mentor`).
- Достижения и прогресс по маршрутам (геймификация).

## Аутентификация

Сервис **не** аутентифицирует — принимает `access`-JWT от `auth_service`
и проверяет подпись локально (**HS256**, общий `JWT_SECRET`). Из токена берутся
`sub` (id пользователя), `role`, `is_root` — см. `Principal` в `api/deps.py`.

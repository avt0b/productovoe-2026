# Frontend — «Маршруты победы»

Два независимых приложения. Общего кода между ними нет и не планируется:
у них разные пользователи, разные устройства и разные контуры аутентификации.

| Приложение | Назначение | Стек | Бэкенд | Статус |
| --- | --- | --- | --- | --- |
| [admin/](./admin/) | Панель администратора: дашборд, модерация, журнал аудита | Vue 3 + Vite + Tailwind | только `admin_service` (8010) | реализовано |
| `client/` | Мобильное приложение и веб-версия для семей, поисковиков и краеведов | не зафиксирован | публичные сервисы (8001–8007) | папка ещё не создана |

## admin/ — панель администратора

Отдельное веб-приложение на Vue 3. Ходит только в `admin_service`, свой контур
входа с TOTP, свои роли (`superadmin` / `admin` / `moderator` / `viewer`).
Подробности, запуск и список экранов — [admin/README.md](./admin/README.md).

```bash
cd frontend/admin && npm install && npm run dev
```

## client/ — приложение платформы

Ещё не начато. По кейсу:

- **Mobile:** Flutter или React Native
- **Карты:** MapLibre / Leaflet / 2ГИС с кастомными слоями («ВОВ», «Последний бой»)
- **AR:** камера + Three.js поверх (WebXR не используем — его нет ни в
  Android WebView, ни в Safari на iOS)
- **Платежи:** ЮKassa в тестовом режиме

Экраны прототипа: «Тропа» (семейный квест), «Поисковикам» (лента задач и
сборов), «Выходные с поисковиком» (календарь и чек-лист), «Последний бой»
(карта с красными и зелёными метками).

AR-модуль стоит делать отдельной страницей со своим бандлом, а не Vue-компонентом:
Three.js владеет собственным циклом отрисовки, и смешивать его с реактивностью
не нужно. Связь с приложением — через URL и один эндпоинт.

## Общие правила

- **Дизайн-токены — в конфиге, не в компонентах.** Палитра, отступы и
  шрифтовые роли перенесены из макета Google Stitch в `tailwind.config.js`.
  Произвольных `#hex` и `px` в разметке быть не должно.
- **Три состояния у каждого экрана:** загрузка, ошибка с повтором, пусто.
- **Типы API генерируются из бэкенда, а не пишутся руками.** Пока в `admin/`
  они выверены вручную (`src/api/types.ts`); при первой же расхождении стоит
  перейти на `openapi-typescript` по схеме из `/openapi.json`.
- **Кириллица в шрифтах обязательна.** Oswald, Work Sans, Noto Serif и
  Space Mono её имеют — при замене проверяйте.

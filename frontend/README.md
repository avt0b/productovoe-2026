# Frontend — «Маршруты победы»

Клиент платформы: мобильное приложение (семейный режим + режим поисковика) и
веб-версия.

## Стек (по кейсу — на выбор)

- **Mobile:** Flutter или React Native (кроссплатформа)
- **Карты:** Leaflet / Mapbox / 2ГИС API с кастомными слоями («ВОВ»,
  «Последний бой»)
- **AR:** Unity-модуль для AR-точек либо Vue.js для веба
- **Платежи:** ЮKassa / CloudPayments

## Экраны прототипа

1. «Тропа» — семейный квест-маршрут с интерактивными точками
2. «Поисковикам» — лента задач и сборов
3. «Выходные с поисковиком» — календарь выездов и чек-лист новичка
4. «Последний бой» — карта мест гибели (красные/зелёные метки)

## Статус

Стек ещё не зафиксирован — папка-заготовка. После выбора инструмента сюда
кладётся проект (`flutter create .` / `npx react-native init` / Vite).
